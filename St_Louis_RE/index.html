Change in average assessment

    How the values were calculated

    Pre covers 2010–2015 and post covers 2016–2019. Each assessment is the arithmetic mean of the available annual total assessed values in that period. Percent change divides the difference between period averages by the pre-period average. A missing or zero pre-period average leaves percent change unavailable.

    Sale prices show the median of the priced transaction rows in each period, with the number of observations. Dollar amounts are nominal. Parcel shapes use the latest available assessment geometry, or the latest sale geometry for parcels with only sales data. Distance uses the thesis export’s stadium distance. Changes shown here are descriptive.
